🚀 Features
Multi-Way Expressions Conversion: Supports full bidirectional translation between:

Infix (Standard notation)

Postfix (Reverse Polish Notation - RPN)

Prefix (Polish Notation)

Custom Math Operators: Allows users to define their own custom mathematical operations and rules.

Stack-Based Architecture: Implements core parsing mechanics (like the Shunting-yard algorithm) using optimized stack data structures.

Interactive UI: Features a clean, desktop graphical user interface for real-time conversion and validation.

🛠️ Tech Stack
Language: Java

Framework: JavaFX (GUI)

Concepts: Stack Data Structures(Stacks,cursorArray), Operator Precedence Parsing
